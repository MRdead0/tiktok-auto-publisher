TikTok Auto Publisher

Aplicativo para Windows desenvolvido para auxiliar usuários na organização e publicação de vídeos em suas próprias contas do TikTok.

Informações

O aplicativo utiliza a API oficial do TikTok para permitir a autorização da conta e a publicação de vídeos, conforme as permissões concedidas.
